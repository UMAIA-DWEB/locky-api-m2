# C1 : LockyAPI - Sistema de Gestão de Cacifos Inteligentes

## Description

A LockyAPI é o backend que desenvolvi para este trabalho. É uma API REST de gestão de cacifos inteligentes inspirada no serviço comercial **Locky Portugal**, que é uma rede real de cacifos disponíveis em centros comerciais, estações de comboios, aeroportos, entre outros.

Escolhi este tema por três razões:

- é um serviço muito usado em Portugal;
- o domínio tem três entidades relacionadas de forma natural (estações, cacifos e reservas), o que cobre logo o mínimo de recursos com uma relação `1:N`;
- as reservas pertencerem a utilizadores faz com que faça sentido implementar OAuth e o controlo de acesso aos próprios recursos.

A API corre em dois contentores Docker (Node + MySQL), tem uma collection Postman e documentação Swagger no formato OpenAPI 3.0. A autenticação é via GitHub (OAuth 2.0) e o controlo de acesso é feito por dois middlewares: `isAuthenticated` e `isOwner`.

### Objetivos

- Implementar uma API REST com 4 verbos HTTP sobre 3 recursos relacionados, sendo um deles relacionado com outro por `1:N`;
- Proteger os recursos com autenticação e autorização, registando na consola o utilizador autenticado em cada pedido;
- Documentar a API segundo a especificação OpenAPI 3.0;
- Distribuir a aplicação como dois contentores Docker (Node + MySQL);
- Aplicar as três valorizações tecnicamente possíveis: Express, OAuth 2.0 e restrição de acesso aos próprios recursos.
